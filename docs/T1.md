## Installation and verification

1. Generate the lockfile.
2. Install locked dependencies, building the model runtime with Metal:

   ```sh
   CMAKE_ARGS="-DGGML_METAL=ON" uv sync --locked --no-binary-package llama-cpp-python
   ```

   This follows the runtime’s documented [build configuration](https://llama-cpp-python.readthedocs.io/en/latest/). Xcode’s compiler and CMake are available locally.

3. Verify all four dependencies and `sqlite3` import successfully.
4. Check that configuration parses, matches the approved limits, and `uv lock --check` passes.

## Completion boundary

T1 finishes when dependency installation, imports, lockfile consistency, and configuration checks pass. Model loading, inference, data processing, and evaluation remain later tasks.
