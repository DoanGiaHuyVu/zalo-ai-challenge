Implement in `solver.py`:

- `load_model(config)` loads the configured artifact with `n_gpu_layers=-1`, memory mapping, the approved 16,384-token context, and seed 42. Resolve relative model paths against the configuration directory.
- Configure the embedded chat template with **`enable_thinking=False`**. The installed chat-completion API does not expose this setting directly; bind it through its existing formatter adapter.
- Verify the rendered assistant prefix closes the empty thinking block before JSON generation.
- `generate_json(model, messages, schema, config)` uses schema-constrained generation, temperature 0, and the approved 1,024-token output cap. Return parsed JSON; raise clear errors for malformed or truncated output.
- Close model resources on completion or failure.

Add a minimal command:

```sh

```
