# T5: Build the source inventory

## Summary

Create the first `data_tools.py` functionality: discover structured files and assign an ID to each selectable CSV, Excel worksheet, and SQLite table.

No model calls, header detection, or business-row loading enter T5.

## Implementation

Add `build_inventory(business_dir)` returning a JSON-compatible catalog with:

- `files`: business-relative filename, format, and size in bytes.
- `sources`: `source_id`, filename, format, and worksheet or table name where applicable.

A CSV contributes one source; a workbook contributes one per worksheet; a database contributes one per user table. Files with no selectable sources remain represented in `files`.

Assign IDs `S001`, `S002`, and onward using sorted relative filenames, workbook worksheet order, and sorted SQLite table names. IDs are scoped to one business and reproducible for an unchanged inventory. Preserve original names, including Vietnamese characters.

Discovery behavior:

- Support `.csv`, `.xlsx`, `.sqlite`, `.sqlite3`, and `.db`, with case-insensitive extensions.
- Include ordinary nested directories. Exclude README and other unsupported files.
- Reject directory symlinks; resolve file symlinks and reject targets outside the business directory.
- Read Excel workbook metadata directly from its ZIP contents, including hidden worksheets.
- Open SQLite read-only and query table names from its schema, excluding internal tables and views.
- Report unreadable or corrupt supported files with their relative filename; do not return a partially successful catalog.

Retain the existing feasibility scanner’s inventory format through a small adapter backed by this shared implementation. Preserve existing T3 reports; do not rerun GPU diagnostics.

## CLI and verification

Add a mutually exclusive, model-free command in `solver.py`:

```sh
.venv/bin/python solver.py --inventory train/data/biz_101
```

Print the catalog as JSON. Exit 0 on success or 1 with a clear error on stderr. Run this branch before configuration or model initialization.

Add focused tests covering:

- Multiple worksheets, hidden worksheets, multiple tables, and empty databases.
- Deterministic IDs, repeated worksheet names across different files, and Vietnamese filenames.
- Nested files, supported extensions, and symlink boundaries.
- Corrupt workbook/database errors with filenames.
- Metadata-only access and resource cleanup.
- CLI execution without model configuration or initialization.
- Compatibility with the existing feasibility inventory.

Run all existing 36 tests plus the new tests. Inventory all 44 released businesses and verify the counts above and that every source maps to its original file and worksheet/table.
