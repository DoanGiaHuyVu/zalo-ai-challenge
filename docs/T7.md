# T7: Inspect raw source rows

## Summary

Implement bounded previews so the agent can identify headers and row layouts before loading data.

Inspection found that **all 438 released worksheets lack declared dimensions**. T7 must stream actual rows and preserve their positions. It must not infer headers, normalize business values, or register business tables.

## Inspection API

Add `inspect_sources(business_dir, inventory, source_ids, *, start_row=1, row_count=12)` in `data_tools.py`. The inventory is supplied by trusted host code; callers select sources through their IDs.

Return one preview per requested source, in request order, containing:

- Source identity and original file/worksheet/table metadata.
- Positional column identifiers such as `c001`.
- Rows with source-row references and cell values.
- The row-reference convention, whether more rows exist, and the next starting row.

Validate IDs and arguments before reading. Recheck resolved source paths against the business directory. Unknown IDs, invalid ranges, changed/missing sources, and read errors produce source-specific errors.

Use these initial bounds: **1–8 unique sources**, **1–50 rows per source**, and **16 KiB for the complete serialized response**. Reject oversized responses with an actionable instruction to request fewer rows or sources; never silently truncate values or omit requested sources. Exact admission into model context remains part of the later loop.

### Format behavior

- **CSV:** use strict UTF-8 with optional BOM and comma delimiters, matching the released files. Preserve strings, leading zeros, whitespace, empty fields, blank records, and quoted multiline fields. `start_row` counts logical CSV records, including headers.
- **Excel:** use openpyxl read-only mode with formulas preserved. Ignore unreliable worksheet dimensions and stream only through the requested window plus one lookahead row. Preserve titles, blank rows, merged-cell blanks, and multiple header rows. Include workbook epoch metadata.
- **SQLite:** open read-only, return declared column metadata, and select a bounded window from the catalog-selected table. Use an accessible rowid for deterministic ordering, falling back to declared primary-key columns for `WITHOUT ROWID` tables. Include the ordering/key information; an ordinal preview position alone is not a durable row identity.

Represent ordinary values as JSON primitives. Encode dates/times as ISO text with explicit type information, preserve numeric Excel serial dates as numbers, and encode binary values with a base64/type marker. Do not evaluate formulas or silently stringify unsupported values.

Read one extra row to determine pagination. Requests beyond the source end return an empty preview; do not fabricate trailing blank rows or scan the entire source merely to calculate its row count.

Close files, worksheet iterators, workbooks, cursors, and connections on success or failure.

## CLI and verification

Add a mutually exclusive, model-free command in `solver.py`:

```sh
.venv/bin/python solver.py --inspect train/data/biz_101 \
  --source-ids S001 --start-row 1 --row-count 12
```

Build the business inventory, call the shared inspection function, and print JSON. Inspection flags are valid only with this mode. Exit 0 on success, 1 for inspection errors, and 2 for invalid CLI arguments. No model configuration is required.

Add focused tests for:

- Titles before headers, two-row headers, missing dimensions, interior blanks, and end-of-source pagination.
- CSV leading-zero IDs, BOMs, quoted newlines, empty fields, and raw money/date strings.
- Excel dates, epochs, merged cells, and unevaluated formulas.
- Read-only SQLite access, ordering, key references, and safely quoted identifiers.
- Batch ordering, unknown IDs, path escapes, output limits, and resource cleanup.
- CLI execution without configuration/model initialization.

Run the existing 63 tests plus new tests. Inspect the first 12 rows of all **502 released sources**, checking original names, row references, JSON serialization, and format compatibility. Public-test inspection remains input compatibility work; generate no business answers.
